## 🔧 Troubleshooting

### Presentation doesn't load
- Check internet connection (needs reveal.js from CDN)
- Try different browser (Chrome recommended)
- Disable browser extensions that block scripts

### Slides look broken
- Clear browser cache (Ctrl+Shift+Delete)
- Update browser to latest version
- Try incognito/private mode

### Keyboard controls don't work
- Click anywhere on presentation first
- Check keyboard focus is on browser window
- Try clicking slide area
