1. Open this page in browser

COMMON PROBLEMS & SOLUTIONS

Problem: Popup appears but buttons don't work

→ Right-click popup → Inspect

→ Check Console for errors

→ Look for "Refused to execute inline script" (CSP error)

→ Check if onclick still in code (should be 0)

Problem: Popup doesn't appear at all

→ Content script not injecting

→ Check manifest.json content_scripts section

→ Verify "matches": ["<all_urls>"]

Problem: Buttons appear but no action

→ Event listeners not attaching

→ Check console for "Uncaught TypeError"

→ querySelector might be failing

Problem: Extension shows old version

→ Chrome cached old files

→ Use Nuclear Reload (Step 8)
