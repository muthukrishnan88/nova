  TROUBLESHOOTING

PROBLEM: No console logs at all
FIX: Content script not injecting
  → Check chrome://extensions/ → Click "Errors" on extension
  → Copy error message and report it

PROBLEM: Console logs appear but popup doesn't show
FIX: CSS not loading
  → Check manifest.json has "popup.css" in content_scripts
  → Check popup.css file exists in extension folder

PROBLEM: Popup appears but buttons don't click
FIX: Event listeners not attaching
  → Check console for: "🛡️ SAFNEX: All event listeners attached"
  → If missing → setTimeout issue, increase delay

PROBLEM: "Extension installed: null" in console
FIX: Testing on file:// URL
  → Extensions don't inject on local files
  → Test on https:// website instead

PROBLEM: Popup disappears immediately
FIX: JavaScript error
  → Check console for red errors
  → Click service worker in chrome://extensions/
  → Check for errors there too
